# Building HMA-OSS Zygisk (PostBoot)

This fork uses the same Gradle build as upstream HMA-OSS. The only difference
is that the produced module ZIP contains the extra PostBoot scripts described
in [`POSTBOOT_PORT.md`](./POSTBOOT_PORT.md).

## Requirements

* JDK 21 (`brew install openjdk@21` or `sdkman install java 21-tem`)
* Android SDK cmdline-tools + platform-tools
* Android SDK Platform 36 (`sdkmanager "platforms;android-36"`)
* NDK is **not** required — HMA-OSS is Java-only; the only native artefact
  (`libzygisk_loader.so`) is pulled in as a compiled dependency by the
  `com.github.aerath-stuff.ZygoteLoader` Gradle plugin.
* ~4 GB free disk space, ~4 GB RAM for Gradle daemons.

## Local build

```bash
# 1. clone this fork
git clone -b postboot https://github.com/<you>/HMA-OSS.git
cd HMA-OSS

# 2. required: create a local.properties
cat > local.properties <<'EOF'
sdk.dir=/absolute/path/to/Android/Sdk
# officialBuild=false is fine for personal builds
officialBuild=false
localBuild=true
EOF

# 3. build the manager app first (produces app/build/outputs/apk/release/*.apk)
./gradlew :app:assembleRelease

# 4. build the Zygisk module ZIP
./gradlew :zygote:assembleRelease

# 5. output
ls zygote/build/outputs/magisk/release/
#   HMA-OSS-ZYGISK-POSTBOOT-<version>-release.zip
```

The produced ZIP is a KernelSU / Magisk module archive containing:

```
module.prop
customize.sh                    (auto-generated by ZygoteLoader plugin)
customize.d/
  00-verify-resources.sh        (auto-generated checksum verifier)
  21-enforce-ksu-kernel.sh
  22-check-zygisk.sh            (rewritten — detects PostBoot provider)
  24-postboot-stage.sh          (new — stages runtime at install time)
  35-install-manager-app.sh
action.sh                       (rewritten — verify + launch)
post-fs-data.sh                 (new)
service.sh                      (new)
uninstall.sh                    (new)
postboot-bootstrap.sh           (new)
postboot-activate.sh            (new)
packages/system_server          (auto-generated)
classes.dex ...                 (compiled HMA code)
zygisk/arm64-v8a.so             (ZygoteLoader shim, loaded by provider)
manager.apk                     (bundled manager APK)
```

## Flashing on device

1. Full device reboot.
2. Trigger KernelSU temporary root (e.g. Root My Galaxy exploit).
3. Install **NeoZygisk-PostBoot** first (via KernelSU Manager → *Install
   from storage*).
4. Install `HMA-OSS-ZYGISK-POSTBOOT-<version>-release.zip`.
5. KernelSU Manager → **Soft Reboot** once.
6. Tap HMA-OSS module → **Action**, or run:
   ```
   su -c '/system/bin/sh /data/adb/modules/hma_oss_zygisk/postboot-activate.sh verify'
   ```

Expected healthy output:

```
RESULT=HEALTHY_INJECTED
PHASE=4
PROVIDER=zygisksu
RUNTIME=/dev/.hma_oss
MODULE_DIR=/data/adb/modules/hma_oss_zygisk
ZYGOTE_PID=<n>
SYSTEM_SERVER_PID=<n>
ZYGOTE_LIB_MAPPED=1
SYSTEM_SERVER_LIB_MAPPED=1
PROVIDER_SOCKET_READY=1
POSTBOOT_MODE=1
```

## Docker build (optional, no local Android SDK required)

```bash
docker run --rm -it \
    -v "$PWD":/src -w /src \
    -e GRADLE_USER_HOME=/src/.gradle-cache \
    mingc/android-build-box:latest \
    bash -c "yes | sdkmanager 'platforms;android-36' && \
             ./gradlew :app:assembleRelease :zygote:assembleRelease"
```

Output ends up in `zygote/build/outputs/magisk/release/`.

## Verifying the ZIP contents before flashing

```bash
unzip -l zygote/build/outputs/magisk/release/HMA-OSS-ZYGISK-POSTBOOT-*.zip \
    | grep -E 'postboot|customize|service|action|uninstall|zygisk/'
```

You should see all of `postboot-bootstrap.sh`, `postboot-activate.sh`,
`post-fs-data.sh`, `service.sh`, `action.sh`, `uninstall.sh`,
`customize.d/24-postboot-stage.sh`, `zygisk/arm64-v8a.so`.

## Troubleshooting

* **`22-check-zygisk.sh` aborts with `ZYGISK_MULTI_ERR`** — you have more
  than one Zygisk provider installed. Uninstall all but one (typically keep
  `NeoZygisk-PostBoot`).
* **Bootstrap status says `RESULT=WAITING_FOR_KERNELSU_SOFT_REBOOT`** —
  perform **one** KernelSU Manager Soft Reboot. Do not manually restart
  zygote.
* **Bootstrap status says `RESULT=NO_ZYGISK_PROVIDER`** — install
  NeoZygisk-PostBoot first.
* **SELinux denials on `/dev/.hma_oss/*`** — this usually means `chcon` is
  not available in the current Toybox. The bootstrap will fall back through
  two label attempts; if both fail, check `dmesg | grep avc` and open an
  issue with the denial trace.
* **`am start ...MainActivity` fails in `action.sh`** — the manager APK
  wasn't installed for the current user. Re-run the module install so
  `35-install-manager-app.sh` re-installs it.
